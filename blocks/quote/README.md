# Quote

Create a two-column table headed **Quote**, with a merged block-name row.
Use named rows Quote, Author, Role and Portrait. Quote is required plain text;
the other rows are optional. Portrait holds an inline image with alt text.
An empty Quote produces no figure. Repeated decoration does not duplicate it.

The output is a native figure containing a blockquote and optional attribution.
Portraits use the existing EDS optimizer at 150 px and load lazily, preserving
their authored alt text rather than requesting full-size Docs artwork.
There are no supplied ratings, invented speakers or default testimonial text.
Use **Quote (placeholder-portrait)** only for a draft awaiting a portrait; its
empty circle is decoration and is omitted from the accessibility tree.

Use only approved testimonial wording and attribution. See the
[Case Study authoring guide](../../styles/case-study.md) for page placement.
