# CTA

Use a one-column Google Docs table named **CTA**. Its content row contains an H2,
a supporting paragraph and action links in separate paragraphs. Format a primary
link in bold and a secondary link in italic, matching the existing EDS button
authoring convention. The block supports one, two or more actions without a fixed
row count. Blank content does not render a banner.

Actions use native links and wrap on smaller screens. New-tab links receive safe
rel attributes; unsupported/malformed URLs stay noninteractive. The gradient and
layout are block-scoped and use existing semantic tokens. No animation or new
dependency is required.
